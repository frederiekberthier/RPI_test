Zo test je een Pi
  1. Steek de tester-SD in de te testen Pi.
  2. Sluit de GPIO-kabels, de netwerkkabel en de USB-fixture aan.
  3. Zet de Pi aan en wacht tot hier “DUT verbonden” staat.
  4. Druk op START TEST (of op Enter).
